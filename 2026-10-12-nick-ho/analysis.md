# Technical Analysis — nickho-motorsports.nl (Webflow build, pub. Sep 2026)

## 1. Stack
- **Webflow** (`data-wf-page/site`, `webflow.shared.css`, `webflow.js`, jQuery 3.5.1). All layout generated by Webflow Designer.
- **GSAP 3.15** + ScrollTrigger + SplitText + CustomEase (CDN `cdn.prod.website-files.com/gsap/3.15.0/`).
- **Lenis 1.1.18** smooth scroll (`lerp:0.1, wheelMultiplier:0.7`), driven from `gsap.ticker`, `lenis.on('scroll', ScrollTrigger.update)`.
- **Swiper 12** bundle (media/gallery sliders), **hls.js 1.6.11** + Bunny Stream background video (`data-bunny-background-init`, `data-player-status` state machine), **Three.js r128** (included, used by custom hero depth / trail effect).
- **Finsweet Attributes v2** (`fs-mirrorclick`), **Slater** custom-code loader (`assets.slater.app/slater/20545.js`), Google gtag `G-TG70X8DDXN`.
- Schema.org `Person` JSON-LD (Nick Ho, Rotterdam, Erasmus University, awards).

## 2. Layout system
- Webflow containers: `.container` + `.padding-global` + `.grid-global` (6-col grid with `bg_lines_wrapper` vertical hairlines overlaying every section).
- Fluid type system: custom `fluid-system-css` — `html{font-size}` interpolated piecewise across 6 breakpoints (13→20px) via `--font-from/to`, `--vw-from/to` coefficients; everything sized in `rem` so the whole site scales smoothly.
- Sections (in order): `section_hero` → marquee → `section_default` (statement) → `section_logo-wall` → `section_about` (#history) → `section_media` → `section_agenda` (#calendar) → `section_sponsorguide` → `section_video` → `section_gallery` → `section_footer` (#contact) + fixed nav (`bold-nav-full`) + loader + 2 custom cursors.
- Logo wall: CSS container-query grid (`container-type:inline-size`, 7 cols desktop with cols 1,2,6,7 used, outer cols offset by `--logo-wall-offset:5.4rem`; 3 cols mobile).
- History: sticky pattern — `.about_images_list` (container) + `.about_images_track` (`padding-block: calc(50vh - 50cqw)`) so each 1:1 image centers in viewport while text chapters scroll past.
- Agenda: `agenda_sticky_wrapper` + `agenda_sticky` with `data-parallax="target"` car image drifting ±12 units.

## 3. Typography
- Headings: **Anton** (`--fonts--heading-font: Anton, Arial, sans-serif`), uppercase, `line-height≈1.1`, sizes via vars (`h1 6rem, h2 4rem, h3 2.5rem, h4 1.75rem`); hero "NICK HO" is viewport-scaled display type.
- Body/buttons: **Helvetica/Arial** (`--fonts--primary-font`), body 1–1.25rem, small .875rem, button 1rem/0.875rem.
- `text-trim-styles`: `flow-root` + `::before/::after` negative-margin trimming (`-0.5lh + Xem`) on all text/heading classes for optical edge alignment.
- Odometer/countdown numerals reuse heading styles with `font-variant-numeric` natural figures.

## 4. Color palette
- `--primary--100: #FED60A` (racing yellow — CTAs, loader, marquee, selection).
- `--black--100: #000`, tints `#00000080/33/#0003/#0000001a/#0000000d`; `--white--100: #fff`, tints `#ffffff80/#fff3/#ffffff1a/#ffffff0d`.
- Base: near-black hero/agenda/footer (`#050505–#0b0b0b`), off-white content (`#f5f3ee`-ish), hairlines white/black at 10–20% alpha. Selection = yellow bg, black text.

## 5. Animation techniques (GSAP et al.)
- **Loader**: full-screen black with giant yellow "98" SVG paths (`data-loader-bg`, `.loader_number`), odometer `data-odometer-element` count + progress bar, then yellow cover wipe (`loader_cover`, `scaleY`), `data-loader-reveal` hero elements stagger in.
- **Hero depth/trail**: `data-trail="stage/layer/depth-map"` + `data-parallax="trigger" (start 0/end 15–35)` layers (bg, car, transparent driver cutout) with mouse-trail + scroll parallax; grayscale depth-map AVIFs (`depth-map-bg/car/nick`) suggest a Three.js displacement/depth mouse effect.
- **Odometer**: custom roller — `[data-odometer-element]` split into `[data-odometer-part=mask/static/roller]` spans, GSAP-translated rollers; countdown `data-countdown` (`00:00:00:00`) ticks to next race.
- **Nav**: `data-navigation-status` state machine; hamburger bars → X, tile `clip-path` wipe, links stagger up + rotate, hover dims siblings (`:has()`), logo uses `backdrop-filter: grayscale+invert` masked by logo PNG.
- **Buttons (`.button-099`)**: split-char skew/slide hover (staggered `--char` delays), bg scale, focus ring, custom `drag`/`click` cursors following pointer with `data-cursor="active/active-edge"` scaling.
- **Scroll reveals**: SplitText headings, `data-svg-scroll` giant background outline text (CONTACT etc.), radial image slider (`.radial_track --radius:100rem`, `.radial_card` positioned on circle, drag to rotate), Swiper media row, hover saturate+scale on `.media-image`.
- **Video**: Bunny HLS bg with placeholder/loading/play-pause/sound state attributes.

## 6. Notable implementation details
- Responsive images everywhere: AVIF `srcset` 500→3000w; separate transparent driver cutout composited over car/bg.
- Favicon variants for light/dark scheme; OG/Twitter thumbnail AVIF.
- Countdown target baked into Slater script; agenda car is color cutout AVIF on black.
- Accessibility gaps typical of Webflow+GSAP: heavy `div`-itis, cursor-dependent affordances, `prefers-reduced-motion` only partially honored.
